# נקודת שמירה - 27.8.2026, לפני סבב השיפורים הגדול

נוצרה לבקשת אדיר לפני ביצוע תוכנית השיפורים (6 נושאים: שני מספרי טלפון,
פתיחת שער חוזרת, זרימת הזמנות, לוג שער, שיחות כפולות, שכתוב תשובות חניה).

## מה שמור כאן
- `business-config.json` - הקונפיג העסקי החי המלא (תפריט, שעות, מדיניות, אירועים)
- `knowledge.json` - כל הידע הנלמד
- `reservations.json` - כל ההזמנות
- `team.json` - רשימת אנשי הצוות (בלי סיסמאות - הן מוצפנות ב-DB בלבד)
- `templates.json`, `media.json`, `settings.json` - הגדרות נוספות

## איך חוזרים אחורה

### קוד (מלא)
```
git checkout backup-pre-batch-27-8       # תג הגיבוי = קומיט dea4279
```
או להחזיר את main: `git reset --hard backup-pre-batch-27-8` ואז deploy.

### פרודקשן (מיידי, בלי build)
Vercel Dashboard → פרויקט cavalli-chatbot → Deployments → למצוא את הפריסה
של קומיט `dea4279` (27.8, "Gate JSON leak fix...") → ⋯ → Promote to Production.

### קונפיג עסקי חי (אם השתבש ב-DB)
להריץ PUT /api/admin/business-config עם התוכן של business-config.json
(השדה `config` מתוך הקובץ), עם כותרת x-admin-token + עוגיית התחברות.

הערה: היסטוריית שיחות והודעות לא מגובה כאן (גדולה מדי) - לפני כל פעולה
