# השרת של קוואלי - הקמה

שלושה תפקידים על שרת וירטואלי אחד (~20 ש"ח/חודש):
שער וואטסאפ עצמאי (WAHA), מתזמן ההודעות לצוות, וסוכן הטאביט.

## מה צריך כדי להתחיל (אדיר)
1. **שרת:** Hetzner CX22 (מומלץ, ~4.5€/חודש) או DigitalOcean - Ubuntu 24.04.
   ליצור חשבון, להקים שרת, ולתת לקלוד גישת SSH (מפתח או סיסמה).
2. **פרטי התזמונים:** נוסחי ההודעות, שעות מדויקות, ומזהי הקבוצות.
3. **סריקת QR** עם טלפון הוואטסאפ ששולח לקבוצות - פעם אחת בהקמה.

## הקמה (קלוד מריץ ברגע שיש SSH)
```bash
apt update && apt install -y docker.io docker-compose-v2 nodejs npm
# העתקת server/ מהריפו, מילוי .env (WAHA_API_KEY אקראי, GreenAPI אם רוצים מעבר הדרגתי)
docker compose up -d
docker logs -f waha        # להציג QR לסריקה
# סוכן הטאביט: העתקת tabit-automation/ + npm install + pm2 start agent.js
```

## מעבר הדרגתי מ-GreenAPI
המתזמן תומך בשני השערים: `GATEWAY=greenapi` שולח דרך GreenAPI הקיים,
`GATEWAY=waha` דרך השער העצמאי. אפשר להתחיל עם greenapi ולהחליף במשתנה
סביבה אחד כשה-WAHA מזווג ויציב.

⚠️ הבוט של הלקוחות נשאר על ה-API הרשמי של מטא - השרת הזה הוא רק
להודעות פנימיות לצוות ולסוכן הטאביט.
